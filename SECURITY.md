# Comunicação de vulnerabilidades

Não inclua tokens, dados de clientes ou exploits contra terceiros em issues públicas.
Use [relato privado no GitHub](https://github.com/matheusfrote/mmm-intelligence-mcp/security/advisories/new)
se habilitado. Se o recurso estiver indisponível, abra somente uma solicitação genérica
de contato privado, sem detalhes de exploração. Não existe SLA de resposta prometido.

Inclua versão/commit, ambiente, impacto, passos mínimos com dados sintéticos e mitigação
sugerida. O foco de manutenção é a linha atual; versões anteriores não têm suporte
de segurança garantido. Consulte [limites de segurança](docs/security.md).

O serviço padrão é local. Sucesso em testes não autoriza exposição pública, acesso a
contas, pentest de serviços externos ou divulgação de dados. Dependências opcionais
têm cadeias próprias de segurança e licença.
